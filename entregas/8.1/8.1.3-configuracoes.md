## Configurações de ambiente (`.env` — obrigatório)

Carregado em `main.dart` via `flutter_dotenv`. Sem `.env` válido, o app **não inicia**.

| Variável | Obrigatória | Padrão se omitida | Uso |
|----------|-------------|-------------------|-----|
| `EBOOK_SITE_BASE_URL` | **Sim** | — | Base do painel PHP (login, perfil, imagens) |
| `EBOOK_API_BASE_URL` | Não | `{SITE}api.php` | Endpoint principal de livros |
| `EBOOK_IMAGES_BASE_URL` | Não | `{SITE}images/` | URLs de capas |
| `EBOOK_THUMBS_BASE_URL` | Não | `{SITE}images/thumbs/` | Miniaturas |

**Modelo versionado:** `.env.example` (placeholders — sem URLs reais).  
**Arquivo local (não versionar):** `.env` — copiar do exemplo e preencher.

```
EBOOK_SITE_BASE_URL=https://seu-dominio.exemplo.com/
# EBOOK_API_BASE_URL=https://seu-dominio.exemplo.com/api.php  (opcional)
```

Arquivos de referência: `lib/core/config/app_config.dart`, `.env.example`.

## Configurações por organização / acervo

| Configuração | Origem | Efeito no app |
|--------------|--------|---------------|
| `acervo_id` | Retornado no login (`AppUser.acervoId`) | Filtra home, categorias, autores, seções, busca |
| Catálogo de livros | API `api.php` | Conteúdo exibido conforme acervo do usuário |
| Políticas de uso | `privacyPolicy.php` | HTML exibido em **Políticas de uso** |

Não há painel in-app para alterar acervo — definido no backend/ADM ao criar a conta.

---

## Configurações por módulo (padrões locais)

| Módulo | Padrão inicial | Observação |
|--------|----------------|------------|
| Home — aba Início | Carrega home + categorias + seções + autores em paralelo | `HomeViewModel.loadHome` |
| Home — destaques | Até 5 livros aleatórios das seções | `_buildRandomFeaturedBooks` |
| Home — continuar lendo | Lista da API + progresso local | `fetchContinueReading` + `ReadingProgressService` |
| Explorar — gêneros | Grid 2×2 em carrossel (retrato) ou grid responsivo (paisagem) | `SearchScreen` |
| Leitor PDF (Windows) | `PdfView` + scroll (sem pinch) | `_usePdfScrollView` |
| Leitor PDF (mobile) | `PdfViewPinch` | Demais plataformas |
| Leitor EPUB | Rolagem contínua; progresso com debounce | `BookReaderScreen` |
| Progresso de leitura local | Página 1 se nunca lido | Chave `reading_progress` em SharedPreferences |
| Favoritos / wishlist | Conjuntos vazios até `ensureLoaded` | `FavoriteViewModel`, `WishlistViewModel` |
| Perfil — badge | Texto fixo **Leitor Assíduo** | `ProfileScreen` |
| Avatar padrão | Ícone `person_rounded` | Quando `userImage` vazio |

## Configurações de autenticação (API)

| Parâmetro | Valor | Arquivo |
|-----------|-------|---------|

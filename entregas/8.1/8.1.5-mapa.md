## Mapa de permissões (resumo)

Ver detalhe em `8.1.2-perfis.md`.

| Área | Usuário autenticado |
|------|---------------------|
| Início + Explorar + catálogo | Acesso total (filtrado por `acervoId`) |
| Leitor + progresso | Ler, marcar, anotar, sincronizar progresso |
| Favoritos + Ler Depois | Ver, adicionar, remover |
| Perfil + configurações | Ver + editar (senha para abrir config) |
| ADM / moderação | Sem acesso in-app |

---

## Mapa de configurações (resumo)

Ver detalhe em `8.1.3-configuracoes.md`.

| Camada | Chave / local | Padrão |
|--------|---------------|--------|
| Ambiente | `.env` → `EBOOK_SITE_BASE_URL` | Obrigatório |
| API livros | `EBOOK_API_BASE_URL` | `{site}api.php` |
| Sessão | `session_user` | vazio → Login |
| Progresso leitura | `reading_progress` | Mapa por `bookId` |
| Organização | `AppUser.acervoId` | Definido no login |
| Tema | `buildAppTheme()` | Claro fixo |

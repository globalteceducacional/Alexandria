# 8.1.1 — Passo 1: Menu principal, abas e ordem de navegação

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.1 — Menu padrão, módulos, perfis e permissões  
**Plataforma:** Flutter | Navegação: `MaterialApp` + rotas nomeadas + `NavigationBar`

---

## O que este passo pede

Listar o **menu principal**, **abas** e **ordem de navegação** do sistema.

---

## Fluxo de entrada (pré-menu)

```
Splash (SplashScreen)
    │
    ├── Sessão válida (AuthViewModel.isLoggedIn) ──► MainScaffold (bottom nav)
    │
    └── Sem sessão ──► Login ──► (sucesso) ──► MainScaffold
```

| # | Tela | Arquivo | Acesso |
|---|------|---------|--------|
| S-00 | Splash | `splash_screen.dart` | Automático ao abrir app |
| S-01 | Login | `login_screen.dart` | Sem sessão |

> **Contas e credenciais:** criação de contas feita **somente no painel ADM**. O app expõe apenas login (e-mail + senha), sem “Criar conta” nem “Esqueci a senha”.

> **Sessão:** persistida em `SharedPreferences` (`session_user` — JSON do `AppUser`). Restaurada no Splash via `AuthViewModel.tryRestoreSession()`.

---

## Menu principal (pós-login)

Implementado em `MainScaffold` (`main_scaffold.dart`).

| Ordem | Aba | Ícone | Label | Conteúdo |
|-------|-----|-------|-------|----------|
| 1 | **Início** | `home_outlined` / `home_rounded` | Início | `HomeScreen` — destaques, continuar lendo, seções |
| 2 | **Explorar** | `explore_outlined` / `explore_rounded` | Explorar | `SearchScreen` — gêneros, autores, busca |
| 3 | **Perfil** | `person_outline` / `person_rounded` | Perfil | `ProfileScreen` — dados, favoritos, Ler Depois |

**Comportamento:** `IndexedStack` mantém estado das três abas; troca instantânea sem recarregar telas.

---

## Navegação secundária (push — stack sobre abas)

### A partir do Início (`HomeScreen`)

| Destino | Tipo | Rota / arquivo |
|---------|------|----------------|
| Detalhe do livro | Push | `/book-detail` → `book_detail_screen.dart` |
| Leitor (PDF/EPUB) | Push | `/book-reader` → `book_reader_screen.dart` |
| Livros de uma seção | Push | `/home-section-books` → `home_section_books_screen.dart` |
| Busca inline | Inline | Campo no AppBar — alterna título **Destaque** ↔ **Buscar livros** |

### A partir do Explorar (`SearchScreen`)

| Destino | Tipo | Rota / arquivo |
|---------|------|----------------|
| Livros por gênero | Push | `/category-books` → `category_books_screen.dart` |
| Detalhe do autor | Push | `/author-detail` → `author_detail_screen.dart` |
| Detalhe do livro | Push | `/book-detail` |
| Busca inline | Inline | Campo no AppBar — alterna **Explorar** ↔ **Buscar livros** |

### A partir do Perfil (`ProfileScreen`)

| Destino | Tipo | Rota / arquivo |
|---------|------|----------------|
| Configurar perfil | Push (após senha) | `/edit-profile` → `edit_profile_screen.dart` |
| Lista completa favoritos / Ler Depois | Push local | `profile_books_list_screen.dart` |
| Detalhe do livro | Push | `/book-detail` |

### A partir do detalhe do livro

| Destino | Tipo | Observação |
|---------|------|------------|
| Leitor | Push | `/book-reader` |
| Autor | Push | `/author-detail` |

              ┌──────────┐      ┌──────────┐      ┌──────────┐
              │  Início  │      │ Explorar │      │  Perfil  │

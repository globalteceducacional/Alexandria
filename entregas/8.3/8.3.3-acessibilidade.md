# 8.3.3 — Passo 3: Acessibilidade, responsividade e legibilidade

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.3 — UX, telas e protótipos funcionais

---

## O que este passo pede

Definir requisitos de **acessibilidade**, **responsividade** e **legibilidade**.

---

## Responsividade

| Breakpoint | Comportamento | Onde |
|------------|---------------|------|
| ≤ 900 px | Conteúdo em largura total | `AppLayout.wideBreakpoint` |
| > 900 px | Corpo limitado (max 1200 px), AppBar full width | `AppConstrainedContent` |
| Explorar — retrato | Gêneros em carrossel 2×2 | `SearchScreen._GenresGrid` |
| Explorar — paisagem / tablet | Grid 2–4 colunas responsivo | Idem |
| Leitor PDF Windows | `PdfView` scroll (sem pinch) | `BookReaderScreen` |
| Desktop | Scroll com mouse habilitado | `AlexandriaScrollBehavior` |

**Padding padrão:** `AppSpacing.screenHorizontal` (16 px) nas listas principais.

---

## Legibilidade

| Requisito | Implementação atual | Meta |
|-----------|---------------------|------|
| Contraste AppBar | Texto branco sobre `primaryDark` | WCAG AA em títulos |
| Fundo leitura | `background` claro (#F5F0E8) | Conforto prolongado |
| Títulos seção | 18–20 sp, bold | Hierarquia clara |
| Labels formulário | `InputDecoration.labelText` | Sempre visíveis |
| Capas com fallback | Ícone `Icons.book` em erro de imagem | Não depender só da capa |
| Sinopse livro | HTML decodificado (`cleanHtmlText`) | Texto legível sem tags |

---

## Acessibilidade

| Requisito | Estado atual | Meta |
|-----------|--------------|------|
| `Semantics` explícitos | Parcial (ícones com `Tooltip` no perfil) | Revisar botões icônicos |
| Tamanho de toque | Botões ≥ 48 px de altura nos CTAs principais | Manter |
| Leitor — navegação por página | Slider + botões no PDF | Melhorar foco teclado desktop |
| Escala de texto do sistema | Sem clamp global (diferente do ByGames) | Avaliar cap 1.0–1.25 |
| Leitura de tela em busca | Campo com `hintText` descritivo | OK |
| Idioma | pt-BR hardcoded | i18n futuro |

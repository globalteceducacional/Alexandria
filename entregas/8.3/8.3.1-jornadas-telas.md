---

## Jornada J-01 — Leitor autenticado (feliz)

```
Splash → Início → toque em livro → Detalhe → Ler → voltar
              │
              ├── Continuar lendo → Leitor (página salva)
              ├── Busca → resultados → Detalhe
              │
              ├── Explorar → Gênero → lista → Detalhe
              │           └── Autor → livros → Detalhe
              │
              └── Perfil → Favoritos / Ler Depois → Detalhe
                        └── Configurar → senha → editar → salvar
```

**Objetivo:** encontrar e ler livros rapidamente; secundariamente organizar favoritos e dados da conta.

**Tempo crítico:** Splash ≤ ~3,2 s até MainScaffold; 2 toques do Início ao leitor (via detalhe).

---

## Jornada J-02 — Primeiro acesso

```
Globaltec / ADM provisiona conta → Splash → Login → MainScaffold (Início)
```

**Sem passos in-app:** cadastro, tutorial, escolha de organização.

---

## Jornada J-03 — Busca sem resultado

```
Início ou Explorar → abrir busca → digitar → “Nenhum livro encontrado…” → limpar → catálogo
```

---

## Jornada J-04 — Erro de login

```
Login → credenciais erradas → mensagem abaixo do form → corrigir → retry
```

---

## Jornada J-05 — Falha ao carregar biblioteca

```
Início → API indisponível → tela de erro + “Tentar novamente” → pull-to-refresh ou retry
```

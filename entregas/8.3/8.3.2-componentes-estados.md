## Estados vazios

| Contexto | Condição | UI |
|----------|----------|-----|
| Busca Início/Explorar | Sem matches | “Nenhum livro encontrado para …” |
| Explorar | Sem categorias API | Ícone + “Explore livros e categorias” |
| Favoritos (Perfil) | Lista vazia | “Você ainda não favoritou nenhum livro.” |
| Ler Depois (Perfil) | Lista vazia | “Adicione livros à lista Ler Depois…” |
| Gênero / Autor / Seção | API sem livros | Mensagem centralizada por tela |
| Políticas de uso | HTML vazio | “Nenhuma política de uso cadastrada.” |
| Perfil — nome | API vazio | Fallback **Leitor** |

---

## Erros e mensagens

| Situação | Feedback | Tipo |
|----------|----------|------|
| Login falhou | Texto vermelho abaixo do form (`auth.error`) | Erro API |
| Login rede | “Erro de conexão. Verifique o servidor.” | Erro rede |
| Home API falhou | `_ErrorView` + botão retry | Erro catálogo |
| Senha config incorreta | SnackBar no diálogo | Erro validação |
| Senhas não coincidem | SnackBar | Erro form |
| Leitor sem arquivo | “Este livro não possui arquivo…” | Erro conteúdo |
| Leitor formato inválido | “Formato não suportado. Use PDF ou EPUB.” | Erro conteúdo |
| Leitor rede | “Erro ao abrir o livro. Verifique sua conexão.” | Erro rede |
| Políticas falhou | Texto centralizado de erro | Erro API |
| Favorito sem login | SnackBar no detalhe | Bloqueio |

---

## Confirmações

| Ação | Padrão |
|------|--------|
| Abrir configurar perfil | `AlertDialog` senha (`barrierDismissible: false`) |
| Cancelar diálogo senha | Botão Cancelar → pop `false` |
| Sair da conta | Botão direto em `EditProfileScreen` — **sem** diálogo extra |
| Marca-página / anotação (leitor) | `showDialog` para texto da nota |

---

## Feedbacks de progresso

| Ação | Feedback |
|------|----------|
| Login | Botão disabled + `CircularProgressIndicator` 22×22 |
| Home inicial | `CircularProgressIndicator` central |
| Busca | Indicador full-screen enquanto `isSearching` |
| Pull-to-refresh Início | `RefreshIndicator` cor `accent` |
| Salvar perfil | `_saving` — botão disabled + spinner |
| Carregar leitor | Loading central até documento abrir |
| Favoritos / Ler Depois (Perfil) | Spinner na seção até API responder |

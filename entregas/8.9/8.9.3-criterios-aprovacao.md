## Reprovado

Bloqueadores — impede uso escolar:

| Condição |
|----------|
| App não instala ou crash na abertura |
| Não loga com credencial válida do kit |
| Crash na Home ou impossível carregar catálogo |
| Nenhum livro abre no leitor (PDF/EPUB) |
| Perda de sessão a **cada** abertura do app |
| Favoritos ou progresso não persistem após uso normal |
| `.env` ausente no build de distribuição |

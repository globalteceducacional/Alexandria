# 8.4.4 — Passo 4: Seeds e configuração inicial para ambiente funcional

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.4 — Banco de dados, entidades e rastreabilidade

---

## O que este passo pede

Definir **seeds** e **configuração inicial** necessária para um ambiente funcional do Alexandria.

---

## Visão geral

O Alexandria **não possui seed de catálogo no app**. Todo conteúdo (livros, categorias, autores, contas) vem do **backend PHP + painel ADM Globaltec**. O “seed” operacional divide-se em:

1. **Servidor** — acervo, livros e usuários provisionados no painel  
2. **Cliente** — `.env`, build e credenciais de teste  

---

## Seeds no servidor (painel ADM — fora do repo Flutter)

| Item | Obrigatório | Descrição |
|------|-------------|-----------|
| Organização / escola | Sim | Tenant com acervo próprio |
| Acervo (`acervo_id`) | Sim | Vinculado ao usuário no login |
| Catálogo mínimo | Sim | Ao menos 1 livro PDF ou EPUB publicado |
| Categorias / autores | Recomendado | Para Explorar e filtros |
| Seções Home | Recomendado | Carrosséis e “Ver todos” |
| Usuário de teste | Sim | E-mail + senha para login no app |
| Políticas de uso | Recomendado | HTML em `privacyPolicy.php` |

> **Contas:** criadas pela Globaltec ou admin da organização — **não** há cadastro in-app (RN-06).

## Configuração inicial do cliente Flutter

### 1. Arquivo `.env`

Copiar `.env.example` → `.env` na raiz do projeto:

```env
EBOOK_SITE_BASE_URL=https://seu-dominio.exemplo.com/
# Opcionais (derivam da base se omitidos):
# EBOOK_API_BASE_URL=https://seu-dominio.exemplo.com/api.php
# EBOOK_IMAGES_BASE_URL=https://seu-dominio.exemplo.com/images/
# EBOOK_THUMBS_BASE_URL=https://seu-dominio.exemplo.com/images/thumbs/
```

| Variável | Obrigatória | Efeito se ausente |
|----------|-------------|-------------------|
| `EBOOK_SITE_BASE_URL` | **Sim** | App lança exceção na inicialização |

### 2. Dependências

```powershell
flutter pub get
```

### 3. Execução (desenvolvimento)

```powershell
flutter run
```

Plataformas suportadas: Android, iOS, Windows (conforme `pubspec.yaml`).

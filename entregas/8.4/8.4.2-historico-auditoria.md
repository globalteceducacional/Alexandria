## O que este passo pede

Definir **histórico**, **trilha de auditoria** e **retenção** dos dados críticos.

---

## Dados com histórico no servidor

| Dado | O que é guardado | Auditoria no app | Retenção sugerida |
|------|------------------|------------------|-------------------|
| Perfil do usuário | Última versão via API | Sem histórico de alterações na UI | Política Globaltec / LGPD |
| Favoritos | Estado atual + metadados de data (`date_added`, `updated_at`…) | Ordenação por data; sem log de ações | Enquanto conta ativa |
| Ler Depois | Estado atual | Sem log de quando adicionou | Enquanto conta ativa |
| Continuar lendo | Página atual por livro | Card “Continuar lendo” na Home | Enquanto conta ativa |
| Marca-página / anotação | Por página + `updated_at` | Sincronizado no leitor | Enquanto conta ativa |
| Comentários | Texto + `dt_rate` | Exibidos no detalhe (se API retornar) | Política do painel ADM |
| Avaliações | Nota por usuário/livro | API existe; UI não implementada | Política do painel ADM |
| Catálogo / acervo | Metadados de livros | Somente leitura no app | Gestão no painel ADM |

## Dados locais (dispositivo)

| Dado | Chave / serviço | Retenção | Sync |
|------|-----------------|----------|------|
| Sessão | `session_user` | Até logout ou limpeza do app | Não |
| Progresso de leitura | `reading_progress` | Persistente no aparelho | Sim → `con_reding_book` |
| Cache favoritos | `favorites_{userId}` | Espelho da API; fallback offline | Sim → `favourite_list` |
| Cache Ler Depois | `wishlist_{userId}` | Espelho da API; fallback offline | Sim → `wishlist_list` |
| Foto de perfil cropada | `{documents}/profile_*.jpg` | Temporária até upload | Upload multipart |

**Sem SQLite:** não há migrations nem tabelas locais de catálogo.

---

## Trilha de auditoria — o que existe vs o que falta

### Rastreável hoje (parcial)

| Evento | Onde fica | Evidência |
|--------|-----------|-----------|
| Login bem-sucedido | Servidor (backend) | App persiste `session_user` |
| Progresso de leitura | Local + servidor | `ReadingProgressService` + API |
| Marca/anotação | Servidor | `book_page_state_save` |
| Toggle favorito / wishlist | Servidor | Estado final na API |
| Alteração de perfil | Servidor | `user_profile_update_api.php` |

### Não auditado no cliente Flutter

- Log de navegação entre telas  
- Log de buscas realizadas  
- Tentativas de login falhas (apenas mensagem na UI)  
- Histórico de versões do perfil  
- Eventos do leitor PDF/EPUB (páginas vistas além do progresso)  
- Audit log estruturado (event sourcing)

## Retenção dos dados críticos

| Categoria | Dado crítico | Retenção operacional | Ação ao logout |
|-----------|--------------|----------------------|----------------|
| Autenticação | `session_user` | Sessão ativa | **Removido** (`AuthViewModel.logout`) |
| Leitura | `reading_progress` | Por livro no dispositivo | Mantido localmente* |
| Listas | `favorites_*`, `wishlist_*` | Cache por usuário | Mantido por `userId` |
| Conta | Perfil, listas, progresso servidor | Conta Globaltec | Dados permanecem no servidor |

\* O progresso local não é apagado no logout — ao logar de novo com o mesmo usuário, o app pode reconciliar com o servidor.

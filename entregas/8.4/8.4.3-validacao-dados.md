## O que este passo pede

Documentar **regras de validação**, **unicidade** e **consistência** de dados.

## Validação — UI (formulários)

| Campo | Regra | Tela |
|-------|-------|------|
| E-mail | Obrigatório; deve conter `@` | Login |
| Senha login | Obrigatória; mínimo 4 caracteres | Login |
| Senha configurações | Mínimo 6 caracteres | `_SettingsPasswordDialog` |
| Nome | Obrigatório (trim não vazio) | `EditProfileScreen` |
| Telefone | Opcional | `EditProfileScreen` |
| E-mail perfil | Desabilitado (não editável) | `EditProfileScreen` |
| Nova senha / confirmação | Se preenchida, devem coincidir | `EditProfileScreen` |

Referência cruzada: RN-04, RN-05, RN-07, RN-08, RN-31 em `8.2.2-regras-negocio.md`.

---

## Validação — ViewModel / serviço

| Entrada | Regra | Componente |
|---------|-------|------------|
| Login API | `success == '1'` → sessão válida | `AuthViewModel.login` |
| `userId` vazio | Bloqueia favoritos, wishlist, progresso sync | `FavoriteService`, `WishlistService` |
| `bookId` vazio | Ignora toggle e progresso | Serviços / leitor |
| Busca vazia | Limpa resultados | `HomeViewModel.search` |
| `totalPages <= 0` | Não salva progresso | `BookReaderScreen._saveProgress` |
| Livro concluído | Remove de Ler Depois automaticamente | `BookReaderScreen` (DA-10) |

---

## Validação — API client

| Entrada | Regra |
|---------|-------|
| HTTP status | 2xx esperado; exceção em falha |
| JSON raiz | Deve conter `EBOOK_APP` ou `Galileu` |
| `fetchBookDetail` | Retry sem `user_id` se HTTP 500 com usuário |
| `toggleFavourite` / `toggleWishlist` | Exige `success == '1'` |
| `addComment` | `comment_text` codificado; exige texto não vazio (RN-26) |
| `updateUserProfile` | Senha enviada só se `newPassword.trim()` não vazio |
| URLs de imagem/arquivo | Resolvidas via `AppConfig.imagesBaseUrl` |

## Validação — ambiente

| Variável | Regra |
|----------|-------|
| `EBOOK_SITE_BASE_URL` | **Obrigatória** — app não inicia sem `.env` (RN-03) |
| `EBOOK_API_BASE_URL` | Opcional; default `{site}api.php` |
| `EBOOK_IMAGES_BASE_URL` | Opcional; default `{site}images/` |
| `EBOOK_THUMBS_BASE_URL` | Opcional; default `{site}images/thumbs/` |

## Unicidade

| Entidade | Regra de unicidade | Onde garantido |
|----------|-------------------|----------------|
| Usuário | E-mail único por conta | Servidor (login) |
| Favorito | Um registro por par `(user_id, book_id)` | Servidor (`toggle_favourite`) |
| Wishlist | Um registro por par `(user_id, book_id)` | Servidor (`toggle_wishlist`) |
| Avaliação | Uma nota por `(user_id, book_id)` | Servidor (`rating_check`) — RN-25 |
| Progresso | Um progresso ativo por `(user_id, book_id)` | Servidor + mapa local por `bookId` |
| Estado de página | Uma entrada por `(user_id, book_id, page)` | Servidor (`book_page_state_*`) |
| Sessão local | Uma `session_user` por instalação | SharedPreferences |

## Consistência de dados

| Cenário | Estratégia | Comportamento |
|---------|------------|---------------|
| Favoritos / wishlist offline | API como fonte de verdade + cache local | Em falha de rede, usa cache; ao reconectar, recarrega da API |
| Progresso de leitura | Escrita local imediata + sync servidor | Salva no `dispose` do leitor; debounce no EPUB |
| Perfil | Optimistic UI | Atualiza local primeiro; sync `user_profile_update_api.php` |
| Catálogo multi-acervo | `acervoId` em todas as chamadas | Usuário só vê livros do seu acervo (RN-11) |
| Detalhe do livro | Fallback sem `user_id` | Evita erro 500 quando dados de usuário conflitam (RN-15) |
| Logout | Limpa sessão | `session_user` removido; cache de listas permanece por `userId` |

---

## Sanitização de conteúdo API

- Textos HTML da API são normalizados para exibição em plain text onde aplicável  
- URLs de capa e arquivo passam por getters de `AppConfig`  
- Comentários enviados com `Uri.encodeComponent`

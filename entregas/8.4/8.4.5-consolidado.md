# 8.4.5 — Passo 5: Diagrama lógico e dicionário de dados

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.4 — Banco de dados, entidades e rastreabilidade  
**Documento:** Consolidado oficial da etapa 8.4

---

## Mensagem-chave

O Alexandria opera com **dois mundos de dados**:

1. **Servidor** — catálogo, conta, favoritos, wishlist, progresso, anotações (API PHP)  
2. **Dispositivo** — sessão, cache de listas e progresso local (SharedPreferences)  

Não há SQLite, migrations nem schema próprio de catálogo no app.

---

## Diagrama lógico consolidado

```
                    ┌─────────────────────────────────┐
                    │     API PHP / BD Servidor       │
                    └─────────────────────────────────┘
                                      │
        ┌─────────────────────────────┼─────────────────────────────┐
        │                             │                             │
        ▼                             ▼                             ▼
   ┌─────────┐                 ┌───────────┐               ┌────────────┐
   │ Usuário │─── acervo_id ──►│  Acervo   │─── filtra ──►│   Livro    │
   └────┬────┘                 └───────────┘               └─────┬──────┘
        │                                                          │
        │ 1:N                                                      │ N:1
        ├──────────► Favorito ◄────────────────────────────────────┤
        ├──────────► Wishlist                                     │
        ├──────────► Continuar lendo                              │
        ├──────────► Estado página (marca/nota)                   │
        └──────────► Comentário / Avaliação                       │
                                                                   │
                                              ┌────────────────────┤
                                              ▼                    ▼
                                         ┌────────┐          ┌──────────┐
                                         │ Autor  │          │ Categoria│
                                         └────────┘          └──────────┘

                    ┌─────────────────────────────────┐
                    │  Dispositivo (SharedPreferences) │
                    └─────────────────────────────────┘

                   session_user   reading_progress   favorites_*
                                                   wishlist_*
```

## Dicionário de dados — resumo

| ENT | Nome | Campos-chave | Origem | Local |
|-----|------|--------------|--------|-------|
| ENT-01 | Usuário | `id`, `email`, `name`, `acervoId` | API login/perfil | `session_user` |
| ENT-02 | Acervo | `acervo_id` | Login | — |
| ENT-03 | Livro | `id`, `title`, `fileUrl`, `fileType` | `api.php` | Memória |
| ENT-04 | Autor | `id`, `name`, `image` | `author_*` | Memória |
| ENT-05 | Categoria | `id`, `name`, `totalBooks` | `cat_*` | Memória |
| ENT-06 | Seção Home | `id`, `title`, `books` | `home_section_*` | Memória |
| ENT-07 | Favorito | `user_id`, `book_id` | `toggle_favourite` | `favorites_{userId}` |
| ENT-08 | Wishlist | `user_id`, `book_id` | `toggle_wishlist` | `wishlist_{userId}` |
| ENT-09 | Continuar lendo | `bookId`, `currentPage`, `totalPages` | `con_reding_book` | `reading_progress` |
| ENT-10 | Estado página | `page`, `is_bookmark`, `note` | `book_page_state_*` | Memória (leitor) |
| ENT-11 | Comentário | `comment_text`, `dt_rate` | `book_id` / `add_comment` | — |
| ENT-12 | Avaliação | `rate` | `submit_rating` | — |
| ENT-13 | SessãoApp | JSON `AppUser` | — | `session_user` |

## Chaves SharedPreferences

| Chave | Tipo | Conteúdo |
|-------|------|----------|
| `session_user` | JSON string | `AppUser.toJson()` |
| `reading_progress` | JSON map | `{ bookId: { currentPage, totalPages } }` |
| `favorites_{userId}` | JSON array | Lista de IDs de livros |
| `wishlist_{userId}` | JSON array | Lista de IDs de livros |

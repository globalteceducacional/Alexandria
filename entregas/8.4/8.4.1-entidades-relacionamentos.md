**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.4 — Banco de dados, entidades e rastreabilidade

---

## O que este passo pede

Listar **entidades**, **campos obrigatórios** e **relacionamentos** dos dados do Alexandria.

---

## Contexto para leitores não técnicos

| Analogia | Significado |
|----------|-------------|
| Prateleira da biblioteca | Livros, gêneros e autores vêm da **API** — não estão em banco local |
| Minha conta | Login, perfil, favoritos e Ler Depois ficam no **servidor** |
| Onde parei de ler | Progresso salvo **no aparelho** e **sincronizado** com o servidor |
| Login | **Servidor** valida; o app guarda a sessão em `session_user` |

---

## Diagrama lógico

```
[API PHP / BD servidor]
    │
    ├── Usuário (login, perfil, acervo_id)
    ├── Acervo / Organização (filtro de catálogo)
    ├── Livro (PDF/EPUB, capa, metadados)
    ├── Autor, Categoria, Seção Home
    ├── Favorito (user + book)
    ├── Wishlist / Ler Depois (user + book)
    ├── Continuar lendo (user + book + página)
    ├── Estado de página (marca/anotação)
    └── Comentário / Avaliação (servidor; UI parcial no app)

[Dispositivo local — SharedPreferences]
    ├── Sessão (session_user → AppUser)
    ├── Progresso de leitura (reading_progress)
    ├── Cache favoritos (favorites_{userId})
    └── Cache Ler Depois (wishlist_{userId})
```

> **Sem SQLite:** o Alexandria não usa banco relacional local — apenas SharedPreferences e cache em memória nos ViewModels.

| ENT-01 | Usuário (`AppUser`) | `user_login_api`, `user_profile_*` | Servidor + `session_user` local |

| ENT-03 | Livro (`Book`) | `api.php` (home, allbook, book_id…) | Servidor (cache em memória) |
| ENT-04 | Autor (`Author`) | `author_list`, `author_id` | Servidor |
| ENT-05 | Categoria / Gênero (`Category`) | `cat_list`, `cat_id` | Servidor |
| ENT-06 | Seção Home (`HomeSection`) | `home_section`, `home_section_id` | Servidor |
| ENT-07 | Favorito | `favourite_list`, `toggle_favourite` | Servidor + `favorites_{userId}` |
| ENT-08 | Wishlist (Ler Depois) | `wishlist_list`, `toggle_wishlist` | Servidor + `wishlist_{userId}` |
| ENT-09 | Continuar lendo | `continue_reading`, `con_reding_book` | Servidor + `reading_progress` |

| ENT-13 | SessãoApp | Após login | SharedPreferences |

## Campos obrigatórios por entidade

### ENT-01 — Usuário (`AppUser`)

| Campo | Obrigatório | Uso |
|-------|-------------|-----|
| `user_id` / `id` | Sim | Chave em todas as chamadas autenticadas |
| `email` | Sim | Login; não editável no perfil |
| `name` | Sim | Exibição no Perfil |
| `acervo_id` / `acervoId` | Sim* | Filtro de catálogo (* definido no login) |
| `phone` | Não | Perfil |
| `user_image` | Não | Avatar |
| `auth_id` | Não | Reservado para login social (não usado na UI) |

### ENT-03 — Livro (`Book`)

| Campo | Obrigatório | Uso |
|-------|-------------|-----|
| `id` | Sim | Chave na API e navegação |
| `book_title` / `title` | Sim | Título na UI |
| `book_file_url` / `fileUrl` | Sim | Download/leitura PDF/EPUB |
| `book_file_type` / `fileType` | Sim | Escolhe viewer (PDF vs EPUB) |
| `book_cover_img` / `coverImage` | Não | Capa (URL via `imagesBaseUrl`) |
| `book_description` | Não | Sinopse no detalhe |
| `author_id`, `cat_id` | Não | Relacionamentos |
| `rate_avg`, `total_rate` | Não | Exibição de avaliação agregada |

### ENT-07 / ENT-08 — Favorito e Wishlist

| Campo | Obrigatório | Uso |
|-------|-------------|-----|
| `user_id` | Sim | Dono da lista |
| `book_id` | Sim | Livro referenciado |

### ENT-09 — Continuar lendo

| Campo | Obrigatório | Uso |
|-------|-------------|-----|
| `con_user_id` / `userId` | Sim | Usuário |
| `con_book_id` / `bookId` | Sim | Livro |
| `current_page` | Sim | Página atual |
| `total_pages` | Sim | Barra de progresso |

### ENT-10 — Estado de página

| Campo | Obrigatório | Uso |
|-------|-------------|-----|
| `user_id`, `book_id`, `page` | Sim | Identificação |
| `is_bookmark` | Não | Marca-página |
| `note` | Não | Anotação textual |

## Relacionamentos

| De | Para | Cardinalidade | Observação |
|----|------|---------------|------------|
| Usuário | Acervo | N:1 | `acervoId` filtra catálogo |
| Usuário | Favorito | 1:N | Toggle via API |
| Usuário | Wishlist | 1:N | Toggle via API |
| Usuário | Continuar lendo | 1:N | Sync local + servidor |
| Usuário | Estado de página | 1:N | Por livro e número de página |
| Usuário | Comentário | 1:N | Leitura no detalhe |
| Livro | Autor | N:1 | `authorId` |
| Livro | Categoria | N:N | `categoryIds[]` |
| Livro | Livros relacionados | N:N | `relatedBooks` |
| Categoria | Livro | 1:N | `cat_id` |
| Autor | Livro | 1:N | `author_id` |
| Seção Home | Livro | 1:N | `bookIds` / `home_section_id` |

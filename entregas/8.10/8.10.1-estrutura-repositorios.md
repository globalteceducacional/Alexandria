## Estrutura do repositório

```
alexandria/
├── lib/
│   ├── core/              # api, config, models, services, theme, layout
│   ├── features/          # auth, home, search, book_detail, reader, profile, …
│   ├── routes/            # app_routes.dart
│   └── main.dart
├── assets/images/         # logo, ícones
├── android/ ios/ windows/
├── entregas/              # Documentação 8.x
│   ├── evidencias/        # E-001 … E-008
│   ├── CONVENCOES.md
│   ├── registro-evidencias-visuais.md
│   └── 8.1 … 8.10/
├── test/                  # widget_test.dart (atualizar — PEN-09)
├── .env.example           # Modelo versionado
├── .env                   # Local (gitignore)
├── pubspec.yaml           # 1.0.0+1; asset `.env`
└── README.md
```

## Separação por tipo de artefato

| Tipo | Local | Versionado? |
|------|-------|-------------|
| Código Dart | `lib/` | Sim |
| Documentação funcional | `entregas/` | Sim |
| Prints homologação | `entregas/evidencias/` | Sim |
| `.env.example` | Raiz | Sim |
| `.env` (valores reais) | Raiz | Não (gitignore) |
| Build artifacts | `build/` | Não |
| Schema BD / migrations | Servidor PHP | Repo backend (externo) |
| Keystore Android produção | Máquina CI / TI | Não no Git |

## Configuração `.env`

| Arquivo | Versionado? |
|---------|-------------|
| `.env.example` | Sim |
| `.env` | Não — valores reais de URL |
| `AppConfig` | Sim — lê variáveis via `flutter_dotenv` |

Setup local:

```powershell
cd C:\Users\Paulo\Desktop\alexandria
copy .env.example .env
flutter pub get
flutter run
```

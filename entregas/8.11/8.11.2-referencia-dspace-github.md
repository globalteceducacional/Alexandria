## Arquitetura técnica (README oficial)

```
DSpace
├── Backend (este repo)     → Java, REST API, OAI-PMH, SWORD
├── Frontend (separado)     → dspace-angular (Angular + TypeScript)
├── Banco                   → PostgreSQL
├── Servlet container       → Tomcat (típico)
└── Contrato REST           → github.com/DSpace/RestContract
```

| Camada | Tecnologia |
|--------|------------|
| Backend | Java |
| API | REST (+ interfaces OAI-PMH, SWORD) |
| Frontend UI | [dspace-angular](https://github.com/DSpace/dspace-angular) |
| Testes | Maven (unit + integration), CI no GitHub Actions |
| Docker | Compose para dev/teste (não production-ready oficial) |

## Pontos fortes técnicos

| Prática | Detalhe |
|---------|---------|
| **Contrato REST publicado** | RestContract separado do código — referência para integradores |
| **Separação backend/UI** | API estável; frontend substituível |
| **Testes automatizados** | Unit + integration via Maven; CI em PRs |
| **Guia de contribuição** | CONTRIBUTING, CODE_STYLE, CODE_CONVENTIONS |
| **Versionamento de releases** | Tags e changelog por versão major (10.0, etc.) |
| **Config por ambiente** | YAML + `.env` no frontend Angular |

## Diferenças em relação ao Alexandria

| Aspecto | DSpace (GitHub) | Alexandria |
|---------|-----------------|------------|
| Linguagem | Java | Dart / Flutter |
| API | REST Java própria | PHP Globaltec (`api.php`, `user_*`) |
| UI | Angular web | Flutter mobile/desktop |
| BD | PostgreSQL | Servidor PHP (fora do repo) + SharedPreferences |
| Escopo repo | Plataforma completa | Cliente leitor |
| Open source | Sim (BSD) | Código cliente; backend proprietário Globaltec |

## O que é o DSpace (visão do site)

Plataforma **open source** para **repositórios digitais institucionais** — bibliotecas, universidades e organizações que precisam **preservar e publicar** acervos digitais (artigos, PDFs, imagens, áudio/vídeo).

| Aspecto | Informação (dspace.org) |
|---------|-------------------------|
| Adoção | +3.000 organizações em produção ou projeto |
| Licença | Gratuito e open source (BSD 3-Clause no código) |
| Idiomas | 22 idiomas na plataforma |
| Formatos | PDF, PNG, JPEG, MPEG e outros |
| Integrações | ORCID, OpenAIRE, ROR, harvesters de dados |
| Comunidade | Lyrasis + mailing lists, membros, service providers |
| Versão recente | DSpace 10.0 (2026) — repositório institucional |

## Pontos fortes observados

| Área | Destaque |
|------|----------|
| **Posicionamento** | Mensagem clara: “Build an Open Digital Repository” |
| **Preservação** | Foco em durabilidade e gestão de formatos |
| **Acesso** | Controle granular por grupos |
| **Ecossistema** | Comunidade ativa, newsletter, eventos, provedores registrados |
| **Recursos** | Download, especificações técnicas, demo (“Try DSpace”) |
| **Governança** | Modelo de membership para sustentação do projeto |

---

## Pontos fracos ou limitações (para o contexto Alexandria)

| Aspecto | Observação |
|---------|------------|
| Público-alvo | Institucional/acadêmico — não app mobile escolar pronto |
| Complexidade | Implantação exige infra (PostgreSQL, Tomcat, Java) |
| UX escolar | Não é leitor “Início / Explorar / Perfil” para aluno |
| Backend Globaltec | Alexandria usa API PHP ebook — **não** substituir por DSpace |
| Onboarding aluno | Site orienta administradores, não fluxo de sala de aula |

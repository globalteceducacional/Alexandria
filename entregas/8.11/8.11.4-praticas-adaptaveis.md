# 8.11.4 — Passo 4: Práticas adaptadas do DSpace (adotadas)

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.11 — Referências modelo, benchmark e comparação prática

---

## O que este passo pede

Selecionar **práticas úteis** do DSpace adaptadas ao Alexandria **sem copiar** a solução de mercado.

---

## Princípio

| Copiar ❌ | Adaptar ✓ |
|-----------|-----------|
| Java backend, PostgreSQL, Tomcat | Manter API PHP Globaltec |
| UI Angular web completa | Manter Flutter leitor |
| Repositório institucional genérico | Biblioteca digital escolar por acervo |

---

## Práticas adotadas (inspiradas no DSpace)

| ID | Inspiração DSpace | O que o Alexandria faz | Onde |
|----|-------------------|------------------------|------|
| ADP-01 | Controle de acesso por grupo | Catálogo isolado por `acervoId` do usuário | `AuthViewModel`, chamadas API |
| ADP-02 | Preservação de formatos | Leitor PDF e EPUB in-app | `book_reader_screen.dart` |
| ADP-03 | Metadados de acervo | Autor, gênero, seções na Home e Explorar | API `api.php`, modelos `Book` |
| ADP-04 | Suporte em camadas | Escalonamento L1 → L2 → L3 (professor → TI → Globaltec) | `8.8.3-processo-suporte.md` |
| ADP-05 | Service providers | Globaltec como suporte L3; TI escola como L2 | `8.8.3`, manual 8.8 |
| ADP-06 | Wiki / docs por release | Pasta `entregas/8.x` com consolidados por etapa | `entregas/` |
| ADP-07 | Config por ambiente | `.env` + `AppConfig` | `main.dart`, `app_config.dart` |
| ADP-08 | Demo / evidências visuais | Credencial de homologação + prints E-001…E-008 | `8.3.4`, `evidencias/` |

| Prática DSpace | Motivo |
|----------------|--------|

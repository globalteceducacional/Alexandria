# 8.2.1 — Passo 1: Fluxo principal do produto (início ao fim)

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.2 — Regras de negócio, fluxos e integrações

---

## O que este passo pede

Descrever o **fluxo principal do produto** do início ao fim, **sem lacunas**.

---

## Atores

| Ator | Descrição |
|------|-----------|
| **Leitor** | Usuário com conta na biblioteca digital |
| **App Flutter** | Cliente Alexandria (mobile / desktop) |
| **API Globaltec** | Backend PHP (`api.php` + endpoints `user_*`) |
| **Painel ADM** | Web (backend) — gestão de acervos e contas (fora do app) |

---

## Fluxo principal — visão geral

```
[Abrir app]
     │
     ▼
[Splash ~2s + restaurar sessão]
     │
     ├── session_user em SharedPreferences? ──SIM──► [MainScaffold: Início | Explorar | Perfil]
     │
     └── NÃO ──► [Login: e-mail + senha]
                    │
                    ├── API success ──► salvar sessão ──► [MainScaffold]
                    └── API fail ──► mensagem erro ──► permanece no Login

[MainScaffold — aba Início]
     │
     ├── Pull-to-refresh ──► recarrega home, seções, continuar lendo
     ├── Busca (ícone) ──► filtra livros/autores via API
     ├── Toque em livro ──► [Detalhe] ──► Ler / Favoritar / Ler Depois
     ├── Continuar lendo ──► [Leitor] na página salva
     └── Ver todos (seção) ──► [Lista da seção]

[MainScaffold — aba Explorar]
     │
     ├── Gênero ──► [Livros da categoria]
     ├── Autor ──► [Detalhe autor] ──► livros
     └── Busca ──► resultados ──► [Detalhe]

[MainScaffold — aba Perfil]
     │
     ├── Meus Favoritos / Ler Depois ──► [Detalhe]
     └── Configurar (engrenagem) ──► [Diálogo senha] ──► [EditProfile]
              │
              ├── Salvar nome / telefone / foto / senha ──► API update
              ├── Políticas de uso ──► HTML do servidor
              └── Sair da conta ──► limpar sessão ──► [Login]

[Detalhe do livro]
     │
     ├── Ler ──► [Leitor PDF ou EPUB]
     ├── Favoritar / Ler Depois ──► toggle API
     └── Avaliar / comentar ──► API

[Leitor]
     │
     ├── Navegar páginas / capítulos
     ├── Marca-página e anotação ──► API + local
     ├── Progresso ──► SharedPreferences + API continue_reading
     └── Voltar ──► pop (livro removido de Ler Depois ao iniciar leitura)
```

## Fluxo F-01 — Inicialização e sessão

| # | Passo | Sistema | Resultado |
|---|-------|---------|-----------|
| 1 | Usuário abre o app | `main()` → carrega `.env` → `SplashScreen` | App inicia ou falha sem `.env` |
| 2 | Animação + delay | 1200 ms animação + 2000 ms delay | `AuthViewModel.tryRestoreSession()` |
| 3 | Decisão | `AuthViewModel.isLoggedIn` | Main ou Login (`pushReplacementNamed`) |

**Sem lacunas:** não existe modo convidado nem onboarding obrigatório.

---

## Fluxo F-02 — Autenticação

| # | Passo | Entrada | Saída |
|---|-------|---------|-------|
| 1 | Login — preenche e-mail e senha | Formulário | Validação local (`@`, senha ≥ 4) |
| 2 | Toque em Entrar | Credenciais | `user_login_api.php` |
| 3 | `success == "1"` | `AppUser` da API | `session_user` + `MainScaffold` |
| 4 | Falha | Mensagem API | Texto de erro na tela |

**Fora do fluxo (regra de negócio):** cadastro, recuperação de senha e gestão de contas → **Globaltec** (backend/ADM); usuário só usa credenciais recebidas.

---

## Fluxo F-03 — Descoberta e catálogo (Início + Explorar)

| # | Passo | Detalhe |
|---|-------|---------|
| 1 | Home carrega dados | Paralelo: home, categorias, seções com livros, autores |
| 2 | Destaques | 5 livros aleatórios das seções |
| 3 | Continuar lendo | API `con_reding_book` + barra de progresso local |
| 4 | Busca | API `search_text` — livros e autores |
| 5 | Explorar gêneros | API `cat_list` → push `CategoryBooksScreen` |
| 6 | Explorar autores | API `author_list` → push `AuthorDetailScreen` |
| 7 | Toque em livro | Push `BookDetailScreen` |

---

## Fluxo F-04 — Leitura

| # | Passo | Detalhe |
|---|-------|---------|
| 1 | Detalhe → **Ler** | Push `BookReaderScreen` |
| 2 | Detecta formato | PDF (`pdfx`) ou EPUB (`epub_view`) |
| 3 | Restaura progresso | `ReadingProgressService` + página salva |
| 4 | Durante leitura | Salva progresso local; sync API com debounce (EPUB) |
| 5 | Marca-página / nota | API `book_page_state_save` |
| 6 | Ao sair | `_saveProgress(syncServer: true)`; wishlist pode remover item |
| 7 | Voltar | Pop para detalhe ou home |

---

## Fluxo F-05 — Perfil e personalização

| # | Passo | Detalhe |
|---|-------|---------|
| 1 | Aba Perfil | Exibe nome, avatar, favoritos, Ler Depois |
| 2 | Configurar | Diálogo senha → `EditProfileScreen` |
| 3 | Editar foto | `image_picker` + `image_cropper` → upload multipart |
| 4 | Salvar | Update local imediato + sync `user_profile_update_api.php` |
| 5 | Sair | `logout()` → Login (stack limpa) |

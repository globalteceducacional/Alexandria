# 8.2.4 — Passo 4: Entradas, saídas, estados e gatilhos

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.2 — Regras de negócio, fluxos e integrações

---

## O que este passo pede

Definir **entradas**, **saídas**, **estados** e **gatilhos** de cada fluxo principal.

---

## F-01 — Inicialização e sessão

| Aspecto | Detalhe |
|---------|---------|
| **Gatilho** | Usuário abre o aplicativo |
| **Entradas** | `.env`; `SharedPreferences` (`session_user`) |
| **Estados** | `animating` → `checking_session` → `routing` |
| **Saídas** | Navegação para `MainScaffold` **ou** `Login` |
| **Persistência** | Sessão lida; não alterada neste fluxo |

---

## F-02 — Autenticação e registro

| Aspecto | Detalhe |
|---------|---------|
| **Gatilho** | Toque em **Entrar** com formulário válido |
| **Entradas** | E-mail, senha; registro: nome, telefone opcional |
| **Estados** | `idle` → `loading` (`AuthViewModel.loading`) → `success` \| `error` |
| **Saídas** | `AppUser` em prefs; stack → Main; **ou** mensagem de erro |
| **Dados saída API** | JSON `EBOOK_APP[0].{success, MSG, user_id, acervo_id, …}` |

---

## F-03 — Catálogo, busca e descoberta

| Aspecto | Detalhe |
|---------|---------|
| **Gatilho** | Aba Início/Explorar visível; pull-to-refresh; busca; toque gênero/autor/livro |
| **Entradas** | `acervoId`; texto busca; IDs categoria/autor/seção |
| **Estados** | `loading` → `loaded` \| `error`; busca: `searching` → `results` \| `empty` |
| **Saídas** | UI com seções; lista filtrada; push detalhe/categoria/autor |
| **Dados saída** | `HomeData`, `List<Book>`, `List<Category>`, `List<Author>` |

### Sub-fluxo — busca

| Gatilho | Entrada | Saída |
|---------|---------|-------|
| `onChanged` no campo | String query | Chamada `search_text` |
| Query vazia | — | `clearSearch()` — volta ao catálogo |
| Sem matches | query | Texto "Nenhum livro encontrado…" |

---

## F-04 — Detalhe, listas e interação social

| Aspecto | Detalhe |
|---------|---------|
| **Gatilho** | Push `BookDetailScreen`; toggle fav/wishlist; avaliar; comentar |
| **Entradas** | `book.id`, `userId`; nota 1–5; texto comentário |
| **Estados** | `loading` → `loaded`; fav/wishlist: `toggling`; rating: `submitting` |
| **Saídas** | UI detalhe; estado fav/wishlist; nota persistida; comentário na lista |
| **APIs** | `book_id`, `toggle_*`, `submit_rating`, `add_comment` |

---

## F-05 — Leitura

| Aspecto | Detalhe |
|---------|---------|
| **Gatilho** | Toque **Ler**; mudança de página/capítulo; sair do leitor |
| **Entradas** | URL/arquivo do livro; progresso salvo local; `userId`, `bookId` |
| **Estados** | `loading_doc` → `reading` → `saving`; EPUB: debounce sync |
| **Saídas** | Página atual; progresso em prefs + API; marcações em API |
| **Persistência** | `reading_progress`; `continue_reading`; `book_page_state_*` |

### Sub-fluxo — formato do documento

| Gatilho | Condição | Saída |
|---------|----------|-------|
| Abrir leitor | URL `.pdf` | `PdfController` / `PdfViewPinch` |
| Abrir leitor | URL `.epub` | `EpubController` |
| Plataforma Windows + PDF | `_usePdfScrollView` | `PdfView` scroll |

---

## F-06 — Perfil e conta

| Aspecto | Detalhe |
|---------|---------|
| **Gatilho** | Aba Perfil; engrenagem; salvar; sair |
| **Entradas** | `AppUser`; senha confirmação; campos editáveis; foto local |
| **Estados** | Perfil: `loading_fav/wishlist` → `loaded`; edit: `editing` → `saving` |
| **Saídas (salvar)** | API update + refresh local |
| **Saídas (logout)** | `session_user` removido → Login |

---

## Matriz consolidada — fluxos × I/O

| Fluxo | Entrada principal | Estado terminal | Saída principal |
|-------|-------------------|-----------------|-----------------|
| F-01 | `.env` + prefs sessão | Main ou Login | Tela inicial |
| F-02 | E-mail + senha | Autenticado / erro | Sessão ou mensagem |
| F-03 | `acervoId` + API catálogo | Home/Explorar renderizado | Navegação conteúdo |
| F-04 | `bookId` + `userId` | Detalhe interativo | Fav, rating, comentário |
| F-05 | Livro + progresso | Leitura em curso / salva | Progresso sync |
| F-06 | Form perfil + senha | Perfil salvo ou logout | API + navegação |

---

## Estados globais do aplicativo

| Estado | Onde | Transição |
|--------|------|-----------|
| `anonymous` | Pré-login | Login success → `authenticated` |
| `authenticated` | Main + fluxos | logout → `anonymous` |
| `acervoId` | `AppUser` | Fixo por sessão (login) |
| `favoriteIds` | `FavoriteViewModel` | Toggle → refresh |
| `wishlistIds` | `WishlistViewModel` | Toggle → refresh |
| `readingProgressMap` | `HomeViewModel` | Leitor save → reload home |

---

## Gatilhos de sistema (não ação do usuário)

| Gatilho | Ação |
|---------|------|
| `BookReaderScreen.dispose` | Salva progresso (sync servidor) |
| EPUB scroll debounce | `saveContinueReading` |
| `FavoritesNotifier` notify | Reload favoritos no Perfil |
| HTTP ≠ 200 | Exceção → UI erro / retry fallback |
| JSON inválido em sessão | Remove `session_user` corrompido |

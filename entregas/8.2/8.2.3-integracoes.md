## Integrações externas — API Globaltec

**Configuração:** `.env` → `AppConfig.siteBaseUrl` / `AppConfig.apiBaseUrl`

### Autenticação e perfil (PHP dedicado)

| Endpoint | Método | Consumidor | Propósito |
|----------|--------|------------|-----------|
| `user_login_api.php` | **POST** | `AuthViewModel.login` | Autenticação (senha no body) |
| `user_profile_api.php` | GET | `fetchUserProfile` | Ler perfil |
| `user_profile_update_api.php` | POST multipart | `updateUserProfile` | Atualizar perfil + foto |
| `privacyPolicy.php` | GET | `fetchPrivacyPolicyHtml` | Políticas de uso |

### Catálogo e conteúdo (`api.php?method_name=…`)

| method_name | Consumidor | Propósito |
|-------------|------------|-----------|
| `home` | `fetchHome` | Dados banner/home |
| `latest` | `fetchLatestBooks` | Livros recentes |
| `allbook` | `fetchAllBooks` | Catálogo completo |
| `book_id` | `fetchBookDetail` | Detalhe do livro |
| `cat_id` | `fetchBooksByCategory` | Livros por gênero |
| `cat_list` | `fetchCategories` | Lista de gêneros |
| `search_text` | `searchBooks` | Busca textual |
| `author_list` | `fetchAuthors` | Lista de autores |
| `author_id` | `fetchBooksByAuthor` | Livros do autor |
| `home_section` | `fetchHomeSections` | Seções da home |
| `home_section_id` | `fetchHomeSectionBooks` | Livros da seção |
| `submit_rating` | `submitRating` | Avaliar livro |
| `rating_check` | `fetchUserRating` | Nota do usuário |
| `continue_reading` | `saveContinueReading` | Salvar progresso |
| `con_reding_book` | `fetchContinueReading` | Listar continuar lendo |
| `add_comment` | `addComment` | Comentário |
| `favourite_list` | `fetchFavouriteListRows` | Lista favoritos |
| `toggle_favourite` | `toggleFavourite` | Favoritar/desfavoritar |
| `wishlist_list` | `fetchWishlistIds` | IDs Ler Depois |
| `toggle_wishlist` | `toggleWishlist` | Toggle Ler Depois |
| `book_page_state_list` | `fetchBookPageState` | Marcações/anotações |
| `book_page_state_save` | `saveBookPageState` | Salvar marcação/nota |

**Protocolo:** HTTP/HTTPS síncrono — **sem filas**, **sem webhooks**, **sem retry automático** global (exceto fallback em `fetchBookDetail`).

**Não utilizados no cliente atual:**

| Endpoint | Motivo |
|----------|--------|
| `user_register_api.php` | Cadastro só no ADM |

## Integrações internas — módulos Flutter

```
lib/main.dart
    ├── dotenv (.env)
    ├── MultiProvider (Auth, Home, Favorite, Wishlist)
    └── MaterialApp → AppRoutes
            ├── SplashScreen ──► AuthViewModel.tryRestoreSession
            ├── LoginScreen ──► AuthViewModel.login
            └── MainScaffold (IndexedStack)
                    ├── HomeScreen ──► HomeViewModel ──► EbookApiClient
                    ├── SearchScreen ──► HomeViewModel (busca/categorias)
                    └── ProfileScreen ──► Favorite/Wishlist VMs
                            └── EditProfileScreen ──► AuthViewModel.updateProfile
            BookDetailScreen ──► BookDetailViewModel
            BookReaderScreen ──► ReadingProgressService + API
```

## Dependências críticas entre integrações

```
Painel ADM (acervo + contas)
        │
        ▼
API Globaltec (api.php + user_*) ◄──── App Flutter
        │
        ├── Imagens (EBOOK_IMAGES_BASE_URL)
        └── Arquivos PDF/EPUB (URLs nos livros)
```

| Dependência | Impacto se indisponível |
|-------------|-------------------------|
| `.env` / API base | App não inicia ou não carrega catálogo |
| API login | App inutilizável (exceto tela Login) |
| `api.php` home/search | Home vazia ou erro |
| Internet no leitor | Não abre PDF/EPUB remoto |
| SharedPreferences | Perde sessão/progresso entre reinícios |

## Decisões automáticas do sistema

| ID | Gatilho | Condição | Ação automática |
|----|---------|----------|------------------|
| DA-01 | Fim do Splash | `isLoggedIn` | `MainScaffold` |
| DA-02 | Fim do Splash | `!isLoggedIn` | `Login` |
| DA-03 | Login API | `success == "1"` | Persistir `AppUser`, ir para Main |
| DA-04 | Login API | `success != "1"` | Exibir `MSG` / erro |
| DA-05 | Login API | Exceção de rede | "Erro de conexão. Verifique o servidor." |
| DA-06 | Home — load | Usuário logado | Passa `acervoId` e `userId` |
| DA-07 | Home — destaques | Seções carregadas | Sorteia até 5 livros |
| DA-08 | Leitor — dispose | Sair da tela | Salva progresso (local + servidor) |
| DA-09 | EPUB — mudança de capítulo | Debounce | Sync progresso servidor |
| DA-10 | Início leitura | Livro em Ler Depois | Remove da wishlist (comportamento leitor) |
| DA-11 | Favoritos alterados | `FavoritesNotifier` | Refresh seção favoritos no Perfil |
| DA-12 | Detalhe livro API falha c/ user | HTTP 500 | Retry sem `user_id` |

# 8.8.3 — Passo 3: Processo de suporte e escalonamento

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.8 — Manual de uso, operação e suporte

---

## O que este passo pede

Definir **cadeia de suporte** de primeiro nível e **escalonamento**.

---

## Escalonamento

```
Leitor / Aluno
       │ problema de uso
       ▼
Professor / Coordenação
       │ não resolve (credencial, catálogo, conta)
       ▼
TI escola (rede, instalação, dispositivo)
       │ não resolve (API, acervo, app)
       ▼
Globaltec (credenciais, backend, build oficial)
```

---

## Suporte de primeiro nível (L1)

**Responsável:** professor ou coordenação na escola.

| Tipo de chamado | Ação L1 |
|-----------------|---------|
| Não encontra livro | Orientar busca, gêneros e autores |
| Esqueceu onde parou | Mostrar card **Continuar lendo** na Home |
| Favorito / Ler Depois | Explicar ícones no detalhe do livro |
| App pediu login | Verificar se sessão expirou; refazer login com kit |
| Senha não funciona | Conferir e-mail; escalar se persistir |
| Livro não abre | Verificar Wi-Fi; tentar outro livro; escalar TI |

**Não resolver em L1:** reinstalação técnica, configuração de `.env`, cadastro de livros no acervo, reset de senha no servidor.

---

## Suporte de segundo nível (L2)

**Responsável:** TI da escola.

| Tipo de chamado | Ação L2 |
|-----------------|---------|
| App não instala | Permissões, espaço, versão do SO |
| Sem internet na sala | Rede Wi-Fi escola |
| Build interno com erro de `.env` | Configurar `EBOOK_SITE_BASE_URL` |
| Tablet compartilhado — troca de conta | Logout + login com credencial correta |
| Teste de fumaça | Login → Home → abrir livro → favoritar |

---

## Suporte de terceiro nível (L3)

**Responsável:** Globaltec.

| Tipo de chamado | Ação L3 |
|-----------------|---------|
| Conta bloqueada / senha reset | Painel ADM |
| Acervo vazio ou livro ausente | Publicação no backend |
| API fora do ar | Infraestrutura PHP |
| Bug confirmado no app | Correção e nova build |
| Novos logins ou acervos | Provisionamento |

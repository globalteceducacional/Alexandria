## Erros comuns

| Problema | Causa provável | Solução |
|----------|----------------|---------|
| “Erro de conexão. Verifique o servidor.” | Sem internet ou servidor fora | Verificar Wi-Fi; tentar de novo; escalar TI |
| “Credenciais inválidas.” / MSG da API | E-mail ou senha errados | Conferir kit; contatar coordenação/Globaltec |
| App não abre (tela branca / crash) | `.env` ausente no build dev | Usar build oficial com `.env` embutido |
| Home vazia ou erro de catálogo | API indisponível ou acervo sem livros | Pull-to-refresh; verificar `acervo_id` no painel ADM |
| “Nenhum livro encontrado para …” | Busca sem resultados | Tentar outro termo; explorar gêneros/autores |
| Livro não abre no leitor | Arquivo ausente ou URL inválida | Verificar upload do livro no painel ADM |
| “Formato não suportado. Use PDF ou EPUB.” | Tipo de arquivo incorreto | Publicar PDF ou EPUB no acervo |
| “Erro ao abrir o livro. Verifique sua conexão.” | Download falhou | Wi-Fi; tentar novamente |
| Favorito / Ler Depois não salva | Sem sessão ativa | Refazer login |
| “Faça login para configurar o perfil.” | Sessão expirada | Login novamente |
| Senha incorreta no diálogo de config | Senha digitada errada | Conferir senha de operação |
| Foto de perfil não atualiza | Falha no upload multipart | Tentar imagem menor; verificar rede |
| Progresso não aparece em “Continuar lendo” | Sync pendente ou `totalPages` inválido | Abrir e ler algumas páginas; sair do leitor |
| Políticas de uso vazias | HTML não cadastrado no servidor | Cadastrar em `privacyPolicy.php` (ADM) |

## Mensagens da API e da UI

| Contexto | Mensagem típica | Onde aparece |
|----------|-----------------|--------------|
| Login falhou | `MSG` da API ou “Credenciais inválidas.” | Texto vermelho no Login |
| Login rede | “Erro de conexão. Verifique o servidor.” | Texto vermelho no Login |
| Home API | Texto do `_ErrorView` + botão retry | Tela Início |
| Busca vazia | “Nenhum livro encontrado para …” | Início / Explorar |
| Favoritos vazios | “Você ainda não favoritou nenhum livro.” | Perfil |
| Ler Depois vazio | “Adicione livros à lista Ler Depois…” | Perfil |
| Senhas diferentes | SnackBar no formulário | Configurar perfil |

Detalhe completo: `8.3.2-componentes-estados.md`.

## Boas práticas

| Prática | Por quê |
|---------|---------|
| Manter Wi-Fi estável durante login e leitura | Catálogo e arquivos vêm da API |
| Usar **Continuar lendo** em vez de buscar de novo | Progresso sincroniza automaticamente |
| Favoritar livros importantes | Acesso rápido no Perfil |
| **Ler Depois** para lista de pendências | Remove ao iniciar leitura (comportamento esperado) |
| Confirmar senha antes de editar perfil | Protege dados da conta em dispositivo compartilhado |
| Não compartilhar senha entre alunos | Cada conta tem acervo e progresso próprios |
| Logout em tablet compartilhado | Evita acesso cruzado entre usuários |

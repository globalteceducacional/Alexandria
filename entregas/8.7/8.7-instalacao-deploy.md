## 3. Instalação local

1. Ligar Apache + MySQL no XAMPP.  
2. `.env`: `EBOOK_SITE_BASE_URL=http://127.0.0.1/apps_global/ebook/` (emulador: `10.0.2.2`).  
3. `flutter run`.  
4. Smoke: login **POST** → home → abrir livro → perfil.

```powershell
curl.exe -s -m 15 -X POST "http://127.0.0.1/apps_global/ebook/user_login_api.php" `
  -H "Content-Type: application/x-www-form-urlencoded" `
  --data "email=CONTA&password=SENHA&type=Normal&auth_id="
```

**Não versionar:** `.env` real, keystore, senhas.

---

## 4. Homolog e produção

1. Apontar `.env` para o ambiente; PHP do servidor com login **POST** (deploy PHP antes ou junto do app POST-only).  
2. `flutter build apk|appbundle|windows --release`.  
3. Assinar; Play / MDM; tag Git `v{version}+{build}`.  
4. Rollout gradual; smoke login POST + home + leitor.

---

## 5. Backup, restore e rollback

| Tema | Procedimento |
|------|--------------|
| Código | Git + tags |
| Contas / acervo | Backup **MySQL** (infra servidor) |
| Dados no device | Não críticos; reinstalar + login |
| Rollback app | Build N-1 na loja/MDM |
| Login fora | Investigar API/BD — app sozinho não resolve |
| Senha esquecida | Reset no ADM Globaltec |

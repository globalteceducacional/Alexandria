## Painéis por perfil

### P-00 — Anônimo

| Painel | Widget | Conteúdo |
|--------|--------|----------|
| Splash | `SplashScreen` | Logo + animação; decide rota |
| Login | `LoginScreen` | E-mail, senha, **Entrar** |

**Estados:**

| Estado | UI |
|--------|-----|
| Idle | Formulário editável |
| Loading | `auth.loading` — botão com spinner |
| Erro credenciais | Texto vermelho (`auth.error`) |
| Erro rede | “Erro de conexão. Verifique o servidor.” |
| Sucesso | `session_user` → `MainScaffold` |

### P-01 — Autenticado

| Painel | Widget | Conteúdo |
|--------|--------|----------|
| Início | `HomeScreen` | Destaques, continuar lendo, seções, busca |
| Explorar | `SearchScreen` | Gêneros, autores, busca |
| Perfil | `ProfileScreen` | Avatar, favoritos, Ler Depois |
| Detalhe | `BookDetailScreen` | Capa, sinopse, ações |
| Leitor | `BookReaderScreen` | PDF/EPUB, progresso |
| Config. perfil | `EditProfileScreen` | Form, foto, sair |

**Estados do Início:**

| Estado | Condição | UI |
|--------|----------|-----|
| Loading inicial | `isLoading && homeData == null` | Spinner central |
| Loaded | API OK | Seções + carrossel |
| Erro catálogo | `error` sem dados | `_ErrorView` + retry |
| Busca ativa | `_isSearchOpen` + query | `SearchResultsSections` |
| Busca vazia | Sem matches | Texto “Nenhum livro encontrado…” |
| Refresh | Pull | `RefreshIndicator` |

**Estados do Perfil:**

| Estado | Condição | UI |
|--------|----------|-----|
| Loading favoritos | `_loading` | Spinner na seção |
| Favoritos vazios | Sem IDs | Mensagem orientativa |
| Ler Depois vazio | Sem livros | Mensagem orientativa |
| Loaded | API OK | Lista de tiles com capa |

**Estados do Leitor:**

| Estado | Condição | UI |
|--------|----------|-----|
| Loading doc | `_loading == true` | Spinner |
| Lendo | Documento aberto | Viewer + controles |
| Erro | `_error != null` | Mensagem + voltar |
| Salvando progresso | dispose / debounce | Silencioso (background) |

## Confirmações e feedbacks

| Ação | Componente | Feedback |
|------|------------|----------|
| Login falhou | Texto inline | `auth.error` |
| Gate config perfil | `AlertDialog` | Senha incorreta → SnackBar |
| Salvar perfil | Botão loading | Pop com `true` |
| Toggle favorito | `FavoriteViewModel` | `FavoritesNotifier` → refresh Perfil |
| Detalhe ações | SnackBar | Mensagens de bloqueio/erro |

Detalhamento visual e mensagens: **`8.3.2-componentes-estados.md`**.  
Evidências de tela: **`8.3.4-prototipo-telas (prints).md`** (E-001…E-008) — **sem replicar imagens nesta etapa**.

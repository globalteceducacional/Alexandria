## Fluxos integrados (uso real)

### F-02 — Login

```
LoginScreen → AuthViewModel.login
  → POST user_login_api.php (body: email, password, type, auth_id)
  → success == '1' ?
       sim → session_user + MainScaffold
       não → auth.error na UI
```

### F-03 — Home

```
HomeScreen.init → HomeViewModel.loadHome(acervoId, userId)
  → paralelo: home, cat_list, home_section, author_list
  → fetchContinueReading(userId)
  → UI com seções e continuar lendo
```

### F-04 — Busca

```
onChanged → HomeViewModel.search
  → _ensureSearchBookIndex (allbook ou fallback local)
  → _rankBooks + _rankAuthors
  → SearchResultsSections
```

### F-05 — Leitura

```
BookDetail → BookReaderScreen
  → HTTP GET arquivo PDF/EPUB
  → ReadingProgressService + saveContinueReading
  → book_page_state_save (marcações)
```

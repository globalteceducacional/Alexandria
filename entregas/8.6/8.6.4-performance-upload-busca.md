## Performance — restrições e otimizações

### App shell

| Área | Decisão | Arquivo / detalhe |
|------|---------|-------------------|
| Abas persistentes | `IndexedStack` mantém 3 abas montadas | `main_scaffold.dart` |
| Conteúdo wide | Max 1200 px centralizado | `AppConstrainedContent` |
| Imagens | `CachedNetworkImage` em capas e avatares | Várias telas |
| Home load | `Future.wait` paralelo (4 chamadas) | `home_view_model.dart` |
| Splash | 2 s delay + animação 1,2 s | `splash_screen.dart` |
| Scroll desktop | Mouse drag habilitado | `AlexandriaScrollBehavior` |

### Leitor

| Área | Observação |
|------|------------|
| PDF mobile | `PdfViewPinch` — pinch zoom |
| PDF Windows | `PdfView` scroll — sem pinch (`pdfx` limitação) |
| EPUB | Rolagem contínua; debounce no sync de progresso |
| Download | HTTP GET do arquivo inteiro na abertura |
| Dispose | Salva progresso síncrono ao sair |

### Rede

| Chamada | Cache / otimização |
|---------|---------------------|
| Home | Recarrega no pull-to-refresh |
| Busca | Índice `allbook` em memória por `acervoId` |
| Detalhe livro | Fallback sem `user_id` evita 500 |
| Perfil update | Update local primeiro, sync depois |

**Meta futura:** timeout uniforme; retry com backoff em redes instáveis.

## Upload de foto de perfil

| Parâmetro | Valor | Código |
|-----------|-------|--------|
| Campo multipart | `user_image` | `updateUserProfile` |
| Seleção | Galeria | `image_picker` |
| Crop | 1:1, max 512 px | `image_cropper` |
| Qualidade | 85 | `compressQuality` |
| Armazenamento temp | `profile_*.jpg` em app documents | `edit_profile_screen.dart` |
| Senha | Opcional no mesmo POST | `request.fields['password']` |

**Restrições servidor:** limite de tamanho definido no PHP — falhas retornam log + mantém dados locais.

## Busca

| Aspecto | Implementação |
|---------|---------------|
| Escopo | Índice `fetchAllBooks` ou fallback das seções carregadas |
| Ranking | `_rankBooks` / `_rankAuthors` — match local |
| Debounce | **Não** — busca a cada `onChanged` |
| API `search_text` | Disponível no client; busca UI usa índice local |
| Paginação | **Não** na busca — lista completa em memória |
| Estado vazio | Mensagem por tela (Início / Explorar) |
| Autores | Seção separada em `SearchResultsSections` |

**Evolução futura:**

| Necessidade | Sugestão |
|-------------|----------|
| Acervos grandes | Debounce 300 ms + `search_text` remoto |
| Paginação catálogo | `page` em `home_section_id` (já suportado na API) |

## Paginação

| Contexto | Paginação hoje | Motivo |
|----------|----------------|--------|
| Home — seções | Carrossel horizontal | Subconjunto por seção na API inicial |
| `home_section_id` | Parâmetro `page` na API | **Suportado no client**; UI atual carrega página 1 |
| Gênero / autor | Lista completa da API | Sem scroll infinito |
| Busca | Não | Índice em memória |
| Favoritos / wishlist | Lista completa | Sem paginação server |

Quando ativar paginação na UI:

- Indicador de fim de lista nas seções longas
- Skeleton durante fetch da página seguinte
- Documentar em 8.6.5

## Limites recomendados

| Recurso | Limite sugerido | Status atual |
|---------|-----------------|--------------|
| Foto perfil | ≤ 512 px após crop | Implementado |
| Índice busca | Memória do `allbook` | OK para acervos médios |
| Leitor PDF | Arquivo inteiro em memória | Risco em livros muito grandes |
| Timeout implícito | HTTP client padrão | Sem timeout custom global |

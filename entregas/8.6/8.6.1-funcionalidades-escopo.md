# 8.6.1 — Passo 1: Funcionalidades do escopo (sem rotas paralelas)

**Projeto:** Alexandria — Biblioteca Digital (Globaltec Educacional)  
**Etapa:** 8.6 — Frontend, funcionalidades e painéis  
**Tipo:** Documentação do estado atual

---

## O que este passo pede

Desenvolver (ou registrar) as **funcionalidades previstas no escopo** evitando **rotas paralelas desnecessárias** — um único caminho de navegação por fluxo.

---

## Princípio de navegação adotado

| Regra | Implementação |
|-------|---------------|
| Uma entrada pós-splash | `SplashScreen` → `Login` **ou** `MainScaffold` |
| Shell único autenticado | `MainScaffold` com `IndexedStack`: Início + Explorar + Perfil |
| Detalhe/leitor via rotas nomeadas | `AppRoutes` — argumentos `Book`, `Category`, `Author` |
| Logout limpa pilha | `pushNamedAndRemoveUntil(AppRoutes.login)` |
| Sem cadastro in-app | Contas provisionadas pela Globaltec / ADM |

> **Rotas removidas:** `/register` — cadastro fora do app (8.1.1).

## Funcionalidades implementadas por módulo

### Autenticação e sessão

| Função | Arquivo | Observação |
|--------|---------|------------|
| Login e-mail/senha | `login_screen.dart`, `auth_view_model.dart` | `user_login_api.php` |
| Persistência sessão | `auth_view_model.dart` | Chave `session_user` (JSON) |
| Restauração no boot | `splash_screen.dart` | Delay 2 s + `tryRestoreSession` |
| Logout | `edit_profile_screen.dart` | Limpa prefs → Login |

### Shell e Início

| Função | Arquivo | Observação |
|--------|---------|------------|
| Bottom nav 3 abas | `main_scaffold.dart` | Início \| Explorar \| Perfil |
| Home API | `home_screen.dart`, `home_view_model.dart` | home, seções, continuar lendo |
| Destaques aleatórios | `home_view_model.dart` | Até 5 livros do pool |
| Busca inline | `home_screen.dart` | Índice local + ranking |
| Pull-to-refresh | `home_screen.dart` | Recarrega `loadHome` |

### Explorar

| Função | Arquivo | Observação |
|--------|---------|------------|
| Lista gêneros | `search_screen.dart` | API `cat_list` |
| Carrossel autores | `search_screen.dart` | API `author_list` |
| Livros por gênero | `category_books_screen.dart` | API `cat_id` |
| Detalhe autor | `author_detail_screen.dart` | API `author_id` |
| Busca compartilhada | `HomeViewModel.search` | Mesmo VM do Início |

### Livro e leitura

| Função | Arquivo | Observação |
|--------|---------|------------|
| Detalhe | `book_detail_screen.dart` | API `book_id` |
| Favoritar | `favorite_view_model.dart` | `toggle_favourite` |
| Ler Depois | `wishlist_view_model.dart` | `toggle_wishlist` |
| Leitor PDF/EPUB | `book_reader_screen.dart` | Download HTTP + render |
| Progresso | `reading_progress_service.dart` | Local + API `continue_reading` |
| Marca-página / nota | `book_reader_screen.dart` | API `book_page_state_*` |

### Perfil

| Função | Arquivo | Observação |
|--------|---------|------------|
| Cabeçalho + listas | `profile_screen.dart` | Favoritos e Ler Depois |
| Gate senha | `_SettingsPasswordDialog` | Re-login |
| Edição conta | `edit_profile_screen.dart` | Multipart + crop foto |
| Políticas | `settings_screen.dart` | `privacyPolicy.php` |

## Mapa de rotas ativo (sem duplicatas)

```
SplashScreen
    ├─ (sem sessão) → Login → MainScaffold
    └─ (com sessão)  → MainScaffold
                          ├─ [aba 0] Home → push → Detalhe → Leitor
                          ├─ [aba 1] Search → Gênero / Autor → Detalhe
                          └─ [aba 2] Profile → push → EditProfile
```

| Destino | Mecanismo | Duplicata evitada |
|---------|-----------|-------------------|
| Login | `pushReplacementNamed` | Único gate anônimo |
| Main shell | `MainScaffold` | Não existe segunda home |
| Detalhe livro | `AppRoutes.bookDetail` | Um widget por livro |
| Busca | Inline no Início e Explorar | Mesmo `HomeViewModel`, não segunda tela de busca |
